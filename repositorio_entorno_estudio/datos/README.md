# Datos

`resumen_agregado.csv` contiene, para cada prueba, el número de participantes (n), la media, la mediana, la desviación estándar y el mínimo y máximo de:

- Puntaje SUS (0 a 100).
- Promedio VRSUQ (1 a 5, con los ítems 3, 8 y 9 recodificados).
- Aciertos de comprensión lectora (0 a 5), solo en la segunda prueba, en condición digital (VR) y física.

Prueba 1: 5 participantes. Prueba 2: 10 participantes.

Los registros por participante **no se publican**, porque el consentimiento informado no contempla compartir datos individuales. Para reproducir el resumen a partir de los Excel originales se incluye `scripts/generar_resumen_agregado.py`. Quien necesite los registros para replicar el análisis puede solicitarlos al autor, que valorará caso por caso.
